# Core Marketplace Structure

Two interfaces:

## 1. User Side
Users can:
- Browse vehicles
- Search vehicles
- Reserve vehicles
- Make payments
- View booking history

Reservation flow:
Browse Vehicle
→ Vehicle Details
→ Reserve
→ Payment
→ Confirmation

Payment methods:
- M-Pesa
- Bank Transfer
- PayPal
- Credit/Debit Cards

---

## 2. Host Side

Hosts can:
- Register
- Subscribe to plans
- Get 30-day free trial
- Add insurance
- Post vehicles
- Manage bookings
- Track earnings

---

# Subscription System

Three-tier subscription model.

Includes:
